## LocalCaption 1.5.0

- Install LocalCaption by dragging it from the disk image into Applications.
- Check for signed updates from the LocalCaption menu or Settings. Automatic checks are optional.
- LocalCaption waits for the transcription session to finish before offering to install an update.
- Transcription, translation, and speaker diarization continue to run on your Mac. Updates preserve downloaded models, settings, and transcript history.
